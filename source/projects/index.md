这里按方向整理当前适合公开展示的项目。早期仓库保留了技术成长轨迹，近期项目则更强调完整闭环、长期运行与跨平台交付。

## 基础平台与 Web 系统

- [MyBaseSystem](https://github.com/sunkejava/MyBaseSystem)：.NET 10 + Vue 3 通用基础系统，采用 DDD 与 Clean Architecture。
- [AirPageSystem](https://github.com/sunkejava/AirPageSystem)：电子墨水屏模板、数据源、任务调度、设备及推送管理平台。
- [VideoCrawler](https://github.com/sunkejava/VideoCrawler)：视频内容采集、解析、任务编排与管理实践。

## 嵌入式与设备

- [CrossMux](https://github.com/sunkejava/crossmux)：面向 Xteink X3/X4 的中文增强固件、文件同步与 MQTT 智能待机。
- [usbipd-win](https://github.com/sunkejava/usbipd-win) / [usbipdcpp](https://github.com/sunkejava/usbipdcpp)：USB/IP 与 Windows 远程 USB 技术研究。

## Windows、网络与工具

- [SuperNAT](https://github.com/sunkejava/SuperNAT)：网络穿透、代理与远程访问实践。
- [Common.Utility](https://github.com/sunkejava/Common.Utility)：C# 常用功能与工具类沉淀。
- [csharp_InlineHook](https://github.com/sunkejava/csharp_InlineHook)：C# 与 Windows 底层机制研究。
- [snoopwpf](https://github.com/sunkejava/snoopwpf)：WPF 运行时检查与调试工具研究。

## 早期 Web 与学习轨迹

公开仓库中还保留了 Java Web、前端组件、CMS、媒体播放、爬虫、桌面 UI、机器学习资料等项目。它们并非都代表当前推荐的技术选型，但完整记录了从 Web 开发向 .NET、Windows、硬件和 AI 工程演进的过程。
